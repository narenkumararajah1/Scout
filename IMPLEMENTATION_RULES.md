# Implementation Rules

These rules apply to every implementation task unless explicitly overridden.

## General

- Follow PROJECT_CONTEXT.md.
- Follow ROADMAP.md.
- Follow DECISIONS.md.
- Implement only the requested milestone.
- Do not implement future milestones.
- Keep the project buildable at all times.
- Do not modify the project architecture unless instructed.
- Do not introduce unnecessary complexity.
- Do not create Git commits unless explicitly instructed.

## Completion

When a milestone is complete:

1. Summarize files created or modified.
2. Summarize what was implemented.
3. Explain how the milestone acceptance criteria were satisfied.
4. Wait for further instructions.
