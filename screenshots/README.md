product.

## Before you publish them

These are going in a public repository. Check each image for:

- **Real prospect names** you would rather not disclose publicly. Analysing
  well-known public companies (NVIDIA, Caterpillar) is safer than showing an
  actual pipeline.
- **The signed-in account address** in the top-right avatar or menu.
- **Executive names and titles.** Scout infers these from public sources; they
  are real people, so treat a screenshot as publication.
- Anything from the Administration page — recipients and delivery configuration.
